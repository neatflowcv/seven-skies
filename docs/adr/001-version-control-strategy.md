# ADR-001: 버전 관리 전략

## 상태

Accepted

## 컨텍스트

프로젝트의 소스 코드 버전 관리 및 협업을 위한 버전 관리 시스템이 필요하다.
다양한 버전 관리 시스템 옵션이 존재한다:

* GitHub
* GitLab
* Gitea

## 결정

**GitHub를 버전 관리 저장소로 사용한다.**

### 선택 이유

1. **광범위한 생태계**: 가장 널리 사용되는 플랫폼으로, 개발자 커뮤니티와의 통합이 용이하다.
2. **CI/CD 통합**: Tekton, ArgoCD 등 다양한 CI/CD 도구와의 통합이 잘 지원된다.
3. **협업 기능**: Pull Request, Issue, Project 등 협업에 필요한 기능이 잘 갖춰져 있다.
4. **무료 플랜**: 오픈소스 프로젝트에 대한 무료 플랜 제공.
5. **보안 기능**: Dependabot, Secret scanning 등 보안 기능 제공.

## 결과

### 긍정적 영향

* 개발자들이 익숙한 플랫폼 사용으로 온보딩 시간 단축
* 다양한 서드파티 도구와의 통합 용이
* 활발한 커뮤니티 지원

### 부정적 영향

* GitHub에 대한 의존성 증가
* GitHub 서비스 장애 시 영향도 존재
